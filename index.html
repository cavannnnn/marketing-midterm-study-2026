去年样题透露什么？今年怎么用？

去年示例卷是英文单选加情境题，包括 SWOT 分类、品牌定位/目标顾客案例、笔记本购买案例；它喜欢考“把概念放到情境里判断”，而不是只默写定义。示例卷标明单选答对 2 分、答错或空题 0 分；今年规则请以老师正式通知为准。

前四份 PPT 直接覆盖、值得优先练： need/want/demand；五种导向；PESTEL；Porter vs benchmark；SWOT 内外；四类消费者影响因素；五阶段决策；购后认知失调；primary/secondary、qualitative/quantitative；研究流程、抽样和洞察。

去年有、前四份 PPT 没系统展开： conscious marketing、选择性注意/记忆、古典/操作性条件反射、观察学习、internal reference price、风险类别、四类购买行为矩阵、Ansoff 增长战略。可能来自去年不同安排或后续内容。先认得，不要误以为这四节已经详细教过：internal reference price 是顾客心中的预期价格；Ansoff 的 market development 是现有产品进入新市场，market penetration 是现有产品在现有市场多卖；conscious marketing 强调伦理、利益相关者和更高目的。

临考 60 秒，脑中走一遍

  1. Need → Want → Demand：匮乏 → 具体想要 → 有钱买。
  2. Create → Capture：先给价值，再拿回报。
  3. Production / Product / Selling / Marketing / Societal：效率 / 性能 / 推销 / 顾客 / 顾客加社会。
  4. Macro / Micro / Internal：社会大环境 / 周围参与者 / 自己的能力。
  5. Porter / Benchmark / SWOT：看行业压力 / 看具名对手 / 汇总内外利弊。
  6. Cultural / Social / Personal / Psychological：文化传统 / 群体家庭 / 个人生活 / 内心活动。
  7. Recognize → Search → Evaluate → Buy → Post-buy：发现问题 → 找资料 → 比选择 → 下单 → 购后反应。
  8. Primary vs Secondary 看“是否为当前决策新收集”；Qualitative vs Quantitative 看“意义/故事还是数字/测量”。
  9. Finding → Insight → Implication：看见了什么 → 为什么重要 → 我们改什么。
  10. STP = Segment → Target → Position：分群 → 选谁 → 在顾客心里占什么位置；好群体记 MASDA。
SESSION 01Introduction

营销是什么

先给顾客价值，再谈回报

Session 1｜营销不是“把东西卖出去”

1. 一句话抓住营销 / What marketing actually means

你想象一家餐厅，后厨已经做了 500 份“老板最爱吃”的三明治。现在老板要求营销部想办法卖掉。这比较像 selling orientation / 推销导向。真正的营销会更早开口：“附近的人赶时间吗？想吃饱、吃健康，还是想便宜？”然后才决定做什么、卖多少钱、去哪卖。

课件定义 / Slide definition (p. 6): Marketing creates value for customers and builds strong relationships, in order to capture value from them in return. 营销先为顾客创造价值、建立关系，再从顾客那里获得回报价值。

这里的 capture value / 获取价值 可以是利润、复购、忠诚、长期客户资产（customer equity）。所以广告、销售、设计 Logo 都可能属于营销，但没有一个能单独代表营销。

考试看到： “marketing = advertising” 或 “selling what the company has produced” → 太窄；“create and capture customer value” → 抓住了完整逻辑。

2. 五步过程：先给，后收 / The five-step marketing process

课件 p. 7 的图可以记成一次“谈恋爱”，但请把它当成商业关系来理解：

  1. Understand the marketplace / 认识市场和顾客。 先知道人家需要什么。别连对方是谁都没搞清楚。
  2. Design a customer-driven strategy / 设计顾客导向战略。 决定服务谁，以及凭什么让人选你。
  3. Construct an integrated marketing program / 设计整合营销方案。 用产品、价格、渠道、传播把承诺变成现实。
  4. Build relationships and satisfaction / 建立关系与满意。 交付体验，别只在付款前热情。
  5. Capture value / 获取回报。 获得利润、复购与长期客户资产。

记忆钩子： 前 4 步 create value / 创造价值，第 5 步 capture value / 获取价值。课件另一套实务说法是 analysis & diagnosis → objectives & strategy → marketing mix → implementation & control，讲的仍是从理解到行动再到衡量。

3. Need、want、demand：一个饿肚子的故事

你中午饿了。饿这件事不是广告发明的；这是 need / 需要。你想吃法棍而不是米饭，这个具体选择是 want / 欲望，受文化、个人口味影响。你还真有钱买，才形成 demand / 有购买力的需求。

背诵版 / In English: A need is a state of felt deprivation. A want is the form a need takes, shaped by culture and personality. A demand is a want backed by buying power. （课件 pp. 9–10）

口诀： 缺什么 → 想要哪一种 → 买不买得起。题目说“她饿、想买某品牌三明治、付得起”，顺序就是 need → want → demand。

紧接着还有四组概念（课件 pp. 11–13）：

  • Market offerings / 市场供给物：满足需要的产品、服务、信息、体验的组合。音乐节卖的绝不只是手环和门票，还卖体验。
  • Customer value / 顾客价值：顾客觉得得到的利益与付出的成本相比值不值。成本可以包括金钱、时间、精力。
  • Satisfaction / 满意度：实际表现和预期比较。承诺 20 小时续航，实际只跑 8 小时，顾客当然不满；即使 8 小时本身不算差。
  • Exchange & relationships / 交换与关系：用自己付出的东西换想要的东西；品牌要争取长期关系，不是只做一次交易。
  • Market / 市场：所有实际和潜在购买者，不是某个实体商场。

Marketing myopia / 营销近视症像什么？电钻厂每天喊“我们的钻头转速更快”，顾客心里却想“我只需要墙上有个洞”。只盯产品规格，不看顾客真正想获得的好处，就是营销近视（p. 11）。

4. 五种导向：五位性格不同的老板

老板常说的话 对应导向 / Orientation 关键判断
“做便宜一点，铺货广一点。” Production / 生产导向 重效率、低成本、可得性。
“继续加功能，做行业最好。” Product / 产品导向 重质量、性能与创新；容易忘记真正需求。
“产品做完了？加大促销冲销量！” Selling / 推销导向 靠积极推销和促销推动购买。
“先问目标顾客需要什么。” Marketing / 市场营销导向 从顾客出发，比对手更好满足需求。
“顾客喜欢，也要考虑社会长期影响。” Societal marketing / 社会营销导向 顾客、企业和社会长期福祉一起考虑。

考试陷阱： 题干只说“满足顾客”＝marketing；再加“环境、社会长期福祉”＝societal marketing。别被选项里的“product”迷惑：品质好不等于顾客真正想买。（课件 p. 16）

5. STP 和 4Ps：决定给谁、怎么给

STP 在 Session 1 是预览，在 Session 5 会完整展开。先分清三个动词：

  • Segmentation / 市场细分：把市场分成需求或特征相近的群体。例：学生、通勤上班族、游戏玩家。
  • Targeting / 目标市场选择：决定重点服务哪一群。例：选“在意维修和耐用的学生”。
  • Positioning / 定位：希望目标顾客在脑中如何看待你的品牌。例：“能陪你读完大学、坏了也容易修的电脑”。

Differentiation / 差异化是你真正做出的不同；value proposition / 价值主张是你承诺给目标顾客的利益。定位不能只写在海报上，必须由实际产品和体验支撑。

4Ps / 营销组合（p. 18）：Product 产品满足什么需要；Price 顾客付出什么；Place 顾客如何买到；Promotion 怎样沟通价值。四个 P 要配合：如果说自己是高端环保品牌，包装、渠道和传播却完全相反，顾客会困惑。

最后，课件提醒三股风会不断改题目：technology & AI / 技术与 AI、globalization / 全球化、sustainability / 可持续性（p. 19）。

SESSION 02Environment

环境与 SWOT

看外面有什么风，也看自己有没有伞

Session 2｜环境分析：别只看天气，还要看自己有没有伞

1. Macro、micro、internal：先画三层圈

想象你经营一家汉堡店。政府开始征收一次性包装税；牛肉供应商涨价；隔壁 Burger King 打折；你自己的 App 老是闪退。它们都影响生意，但住在不同的“圈”里：

  1. Macro environment / 宏观环境：社会层面的力量，你通常控制不了，只能预判和适应。包装税在这里。
  2. Micro environment / 微观环境：靠近企业的参与者，你能产生一定影响，但不能完全控制。供应商、顾客、竞争者、外卖平台、中间商、公众都在这里。
  3. Internal / 内部：本公司拥有或缺少的资源、能力、品牌资产。你自己的 App 问题在这里。

考试先问“谁造成的？” 法规或通胀 → macro；某个供应商/对手 → micro；自己的能力/缺点 → internal。（课件 pp. 5–11）

2. Fad、trend、megatrend：热闹不等于趋势

Fad / 一时风潮：短、难预测，可能下个月就没人提；trend / 趋势：持续、有方向、相对可预测；megatrend / 大趋势：缓慢形成、影响广泛而长期，例如气候变化。拿一时热搜当十年战略，等于拿烟花当路灯。（课件 p. 7）

3. PESTEL：给外部环境拍一张六格照片

字母 中英文 题目里的典型线索
P Political / 政治 政府政策方向、对外关系
E Economic / 经济 通胀、购买力、收入、利率、经济衰退
S Sociocultural / 社会文化 人口年龄、家庭、价值观、生活方式变化
T Technological / 技术 AI、电商、自动化、数字平台
E Environmental / 生态环境 水、能源、污染、废弃物、生物多样性
L Legal / 法律 产品安全、包装、广告、商业法规

两个 E 不一样：economic = 钱和经济条件，environmental = 自然环境。做 PESTEL 要指定市场，比如“法国的快餐市场”，找最重要且有来源的事实，再说明对品牌是机会还是威胁；不是把六个字母每格硬塞一个词。（课件 p. 8）

4. 看竞争要两种镜头：广角和特写

广角：Porter’s Five Forces / 波特五力（p. 12）。 它问“这个行业的竞争压力从哪来，行业是否有吸引力？”五力为：existing rivalry 现有竞争、new entrants 新进入者、substitutes 替代品、supplier power 供应商议价能力、buyer power 买方议价能力。注意替代品不一定同类：不吃汉堡改吃便利店便当，也能解决“快速吃午餐”的需要。

特写：Competitor benchmarking / 竞品对标（pp. 13–14）。 选两个具名对手，用顾客在乎的标准并排比较，如价格、速度、产品范围、App 体验。它回答“和这些具体对手相比，我哪点强、哪点弱？”要同一市场、标准一致，别拿苹果比橘子。

记忆： Porter 看行业压力；benchmark 看品牌对品牌。

5. SWOT：内外分错，一整题都可能错

SWOT 不是把想到的东西随手塞进四格。先判断 内部还是外部，再判断 有利还是不利：

有利 / Positive 不利 / Negative
内部 Internal S = Strength / 优势 W = Weakness / 劣势
外部 External O = Opportunity / 机会 T = Threat / 威胁

比如开法式糕点店：你有蓝带糕点师资格 → S；你不懂营销 → W；当地手工糕点需求上升 → O；附近老牌面包店扩张 → T。这里最有用的问题是：“这是我已经拥有/缺少的东西，还是外部正在发生的事？”（课件 pp. 18–22）

交叉 SWOT / Crossed SWOT（p. 21） 继续问“所以怎么办”：SO 用优势抓机会；WO 借机会补短板；ST 用优势抵御威胁；WT 同时降低弱点与威胁带来的风险。SWOT 最终要能指导行动，不能停留在四格填空。

边界提醒： Session 2 的项目页提到 TAM/SAM/SOM 与粗略需求估算，但这些页没有系统讲计算方法。别把它误当前四份 PPT 已完整讲过的公式章节。

SESSION 03Consumer behavior

消费者行为

从发现需要到购后推荐

Session 3｜消费者的大脑不是“点击购买”按钮

1. 四类影响因素：是谁在推你下单？

Consumer behavior / 消费者行为是最终消费者（个人和家庭）为了个人消费而购买商品与服务的行为（p. 5）。课件把原因分成四个抽屉。想象你买一双跑鞋：

抽屉 里面装什么 跑鞋例子
Cultural / 文化因素 culture 文化、subculture 亚文化、social class 社会阶层 你所在文化怎么看运动；社会阶层也受职业、教育影响，不只看钱。
Social / 社会因素 reference groups 参照群体、family 家庭、roles & status 角色与地位 你想加入的跑团都穿某品牌。
Personal / 个人因素 年龄、职业、经济状况、lifestyle 生活方式、personality 个性、自我概念 你平时热爱马拉松，也有买专业鞋的预算。
Psychological / 心理因素 motivation 动机、perception 知觉、learning 学习、beliefs & attitudes 信念与态度 你觉得某鞋“看起来更稳”，或过去穿过很舒服。

Reference groups / 参照群体还分三类：membership 已加入；aspirational 想加入；dissociative 不想被归进去。看到“想被网红跑者群体接受”，直接找 social / reference group，别被“想”字带到 psychological。（课件 pp. 6–10）

小补丁 / Key terms: Motivation 是强到推动行动的需要；perception 是对信息的选择与解释；learning 是经验带来的行为改变。AIO = Activities, Interests, Opinions，是描述生活方式的活动、兴趣、观点。

2. 买盐和买电脑，不能用同一个营销剧本

Routine / 日常型购买参与度低，几乎按习惯拿；品牌要容易找到、容易想到。Occasional / 偶发比较型会快速比几个选项；品牌要让关键利益一眼能看懂。Complex / 复杂型通常价格或风险较高，顾客花时间研究；品牌要提供评价、清楚的信息和保证。（课件 p. 13）

去年样题用了 extended buying decision making 这样的术语，和课件所说的高参与度复杂决策意思相近，但四类购买行为矩阵并非这四份课件的系统内容。做今年复习，优先掌握课件的“低—中—高参与度”逻辑。

3. 五阶段决策：拿“电脑坏了”走一遍

  1. Problem/need recognition / 问题或需要认知： 电脑跑不动课程软件，“现在这样不行”。
  2. Information search / 信息搜寻： 查测评、问同学、看 YouTube。
  3. Evaluation of alternatives / 备选方案评估： 比较 A、B、C 三台的价格、性能、可维修性。
  4. Purchase decision / 购买决策： 下单。
  5. Post-purchase behavior / 购后行为： 使用后满意、不满、怀疑、复购或推荐。（课件 p. 14）

最容易混： “看不同型号的资料”可以偏信息搜寻；“按几个标准比较和筛选型号”更明确是备选方案评估。看题干的动作，别只看产品名。

数字平台没有取消这五步，只是让它们更快、更公开：社媒可能触发需要，评论影响搜寻与比较，一键支付降低购买摩擦，购后差评或推荐会影响下一位顾客。（课件 p. 15）

4. 买完不是剧终：认知失调和顾客旅程

你刚花很多钱买电脑，第二天看到别人说另一款更好，心里一咯噔：“买错了吗？”这叫 cognitive dissonance / 认知失调，即重大购买后的疑虑。清晰说明、售后支持和保修有助于缓解。Satisfaction / 满意仍看实际体验与期望的差距；体验好可能带来 retention / 留存 和 advocacy / 主动推荐。（课件 p. 18）

Customer journey map / 顾客旅程图把顾客从最初接触到推荐的路径画出来，标出每一步的 action 行动、emotion 情绪、touchpoint 接触点。课件项目版的顺序是 Awareness → Consideration → Purchase → Experience → Advocacy / 认知→考虑→购买→体验→推荐。它比五阶段购买模型更强调体验与关系。（课件 pp. 19–25）

Empathy map / 同理心地图帮助团队整理顾客的需求、想法、感受与痛点；buyer persona / 买家画像把一个目标群体变成基于真实资料的半虚构代表人物，包括目标、痛点、媒体使用等。可以先假设，但不能把假设当成证据。画像最后要能帮助做产品、价格、渠道和传播选择。（课件 pp. 26–29）

SESSION 04Marketing research

营销研究

让想法经得起证据检验

Session 4｜“我觉得顾客会喜欢”不是研究结论

1. 数据如何变成洞察？

Marketing research / 营销研究是为一个具体营销决策，系统地设计、收集、分析和报告相关数据（p. 5）。课件 p. 6 的梯子很重要：

Data 数据 → Information 信息 → Insight 洞察 → Decision 决策 → Learning loop 学习循环。

比如产品页有 68% 的访问者离开，这是数据/发现。整理后发现多数人在介绍区离开，是信息。访谈发现“大家看不懂这产品到底解决什么问题”，才是洞察。于是把页面首屏改写清楚，是决策。上线后再测效果，是学习循环。

考试看到： 一个数字通常只是 finding / 发现；解释顾客为什么会这样，才更像 insight / 洞察；要改什么，是 implication / 行动启示。

2. 信息系统：家里已有的、外面持续看的、专门去问的

MIS / Marketing information system / 营销信息系统收集、评估和分发有用信息，主要有三个来源（课件 pp. 8–10）：

  • Internal data / 内部数据： 销售记录、CRM、客服、网站分析。很快，但往往只能告诉你顾客做了什么，不能说明原因，而且只覆盖已有顾客。
  • Marketing intelligence / 营销情报： 持续看竞争者、媒体、趋势、公开评论。像一部日常雷达。
  • Marketing research / 营销研究： 围绕一个重要的、仍缺证据的决策，专门设计研究。像为某个问题拍一次细致的检查片。

数据越多不一定越懂顾客。来源差、样本偏，百万条记录也可能把人带偏。拿到材料先问四句：Reliable 可靠吗？Relevant 相关吗？Timely 够新吗？Actionable 能改变决策吗？ 权威报告如果研究的是另一个国家、另一种人群，也可能不适合你的问题。（课件 pp. 7、11）

3. 研究流程：先想“要决定什么”，再打开问卷软件

你要不要上市一款新饮料？“大家喜不喜欢我们的创意？”太宽，而且容易诱导受访者给你面子。更好的问题是：“哪类人在哪个场景下真的有这个需求？哪些证据会让我们推出、修改或放弃？”

五步 / Five steps（课件 pp. 14–19）：

  1. Define / 定义问题和待做决策。
  2. Objectives / 明确想知道什么。
  3. Plan / 设计来源、方法、样本、问卷/访谈提纲和分析。
  4. Implement / 收集、清理、分析。
  5. Interpret & report / 解释、报告，并给出行动启示与局限。

研究目标有三种常见类型：Exploratory / 探索性问“这问题究竟是什么、为什么”；Descriptive / 描述性问“谁、多少、频率和偏好怎样”；Causal / 因果性问“改变 X 是否导致 Y 改变”。小便利样本能帮你探索，却不能因为看到相关性就声称“证明了因果”。（课件 p. 16）

4. 两组经常串台的词：来源 vs 方法

第一组问资料从哪来：

  • Secondary data / 二手数据：别人或过去已收集好的资料，例如政府统计、行业报告、已有公司销售记录。快，但要查时间、可靠性和是否适用。
  • Primary data / 一手数据：为了当前这个决策新收集的资料，例如新访谈、新问卷、新观察、新实验。更贴题，通常更费时。

第二组问资料长什么样、怎么分析：

  • Qualitative research / 定性研究：理解意义、故事、动机、语言；常用访谈、焦点小组、观察和开放式回答。
  • Quantitative research / 定量研究：用数字测量变量、描述比例与差异；常用结构化问卷和实验。

这两组是两条独立的轴。你新做的深度访谈＝primary + qualitative；你新发的量表问卷＝primary + quantitative。一份现成的政府统计＝secondary + quantitative。不要看到“问卷”就自动说“二手”，也不要把“定量”误认为“一手”。（课件 pp. 22–24）

Mixed method / 混合方法可以先访谈找痛点，再用问卷比较常见程度。Observation / 观察看到实际行为；social listening / 社交聆听看公开讨论，但公开评论不代表所有消费者。

5. 问卷与抽样：好问题不能自己带答案

“你觉得我们优秀又便宜的新产品有多棒？”这不是问题，这是营销部给自己鼓掌。它既诱导，又把“优秀”和“便宜”两件事混在一起。好的题目要清楚、中立、一次问一件事；先筛选目标受访者，再从容易的一般问题走向较敏感问题，正式发放前先试填。（课件 p. 25）

Open-ended / 开放题适合发现顾客自己的语言；closed-ended / 封闭题适合比较；Likert scale / 李克特量表测程度；ranking / 排序测优先级。

如果你只问了 25 个同学，“25 个受访者中有 17 人表示愿意尝试”是诚实的；“法国年轻人都愿意买”就跨了太大一步。要说明谁回答、人数、如何招募、谁没被覆盖、有什么偏差。便利样本适合初探，不能自动代表总体。课件给课堂小研究的示例规模是 4–6 次访谈或 20–30 份探索问卷，这不是统计代表性保证。（课件 pp. 24、26）

6. AI 与伦理：可以帮忙整理，不能帮忙“生”受访者

AI 可以帮你列假设、找待核实的来源、检查问卷是否诱导、把真实访谈归类。但不能编造受访者、访谈引言、统计数字或来源。研究者要回查原始证据，说明 AI 做了什么，并对结论负责。对真实参与者，要讲明用途、只收必要信息、保护隐私、如实报告方法和限制。（课件 pp. 27–28）

写洞察的句式 / Insight formula（p. 33）： [target] experiences [tension] when [context], creating an opportunity for [brand] because [reason to believe]. 中文就是：“哪类人，在什么场景遇到什么矛盾；证据为什么表明品牌有机会解决？”

SESSION 05Segmentation · Targeting · Positioning

STP：别对全世界喊话

先找到谁值得服务，再想清楚：他为什么会选你？

1. 同样是奶酪，为什么要分两种人格？ / Why STP?

想象你卖一块奶酪。你可以对所有人喊“这是奶酪，请购买”，大概率只能换来一片礼貌的沉默。课件里，Babybel 面向孩子与家庭，抓下午零食；Apéricube 面向成人社交，抓餐前小酌。同一品类，服务的人、使用场景和承诺都不同。（课件 pp. 3–5）

一口气背完 / The chain: Segmentation 把市场分成需求相近的群体 → Targeting 选择最值得且最有能力服务的群体 → Positioning 在这群人的心中形成清楚、不同的印象。
Divide → Choose → Occupy. 没分群就没法精准选择；没目标顾客就谈不上对谁定位。

2. Segmentation：细分市场，不是在 Excel 里随便画格子

Market segmentation / 市场细分：按共同的需要、特征或行为，把广阔市场拆成更小的买家群体。目的不是让表格看起来很努力，而是把产品、信息和预算给更可能回应的人。（课件 p. 7）

细分标准 / Basis看什么 / What it means快速判断 / Example
Socio-demographic / 社会人口年龄、性别、收入、职业、家庭、教育“月收入”“有孩子的家庭”是人的可描述属性。
Geographic / 地理国家、地区、城市/乡村、气候、语言“只服务尼斯附近居民”先看住在哪。
Psychographic / 心理图像生活方式、价值观、态度、社会地位“重视环保、喜欢极简生活”问怎么想、怎么活。
Behavioural / 行为使用场合、追求的利益、忠诚度、使用频率“健身前喝”“想要无咖啡因”“高频购买”问怎么用、为什么买。

易错点： “学生”主要是人口/身份描述；“考前熬夜时喝”是使用场合，属行为；“担心环境影响”更接近价值观，属心理图像；“想要低糖”是追求的利益，属行为。现实中可组合多个标准，题目则通常问主要标准。（课件 pp. 8–13）

分出来还要做体检，记 M-A-S-D-A（课件 p. 14）：

条件一句人话 / Exam cue
Measurable / 可衡量能估计有多少人、他们是什么样吗？
Accessible / 可到达能通过渠道接触并实际服务他们吗？
Substantial / 有足够规模或利润值得花资源吗？小众也可能利润可观。
Differentiable / 可区分与其他群体对营销方案的反应真的不同吗？
Actionable / 可执行公司能为他们设计并实施具体方案吗？

记忆： “数得出、够得着、值得做、分得开、做得到”。例如“喜欢让生活更美好的人”听起来动人，但难以界定和触达，可能过不了前两关。

3. Targeting：选目标，别只盯着最大的蛋糕

面对几个合格的细分市场，还要判断 size & growth / 规模与增长、structural attractiveness / 结构吸引力（竞争、新进入者、替代品、买方力量等），以及 company fit / 企业契合度（目标、资源、能力）。大市场若竞争太强，或公司根本服务不了，不是好目标。（课件 p. 18）

策略 / Strategy服务范围想象一下
Mass / undifferentiated / 无差异大众一个方案给整个市场“一锅汤，大家喝一样的。”
Differentiated / 差异化几个群体，各有不同方案“儿童餐、素食餐、运动餐分开做。”
Concentrated / niche / 集中或利基聚焦一个狭窄群体并服务好“小店只做跑者赛前早餐。”
Individualized / 个体化按每个顾客定制“每个人一份专属菜单。”

陷阱： “四种细分标准”是怎么分人；“四种目标策略”是分完后服务几个群体、如何服务。小品牌资源有限、想深耕一个窄市场，多半选 concentrated；为多个群体做不同产品，是 differentiated。（课件 pp. 19、23）

Empathy map / 同理心地图帮助整理顾客所想、所见、所做与痛点；buyer persona / 买家画像把目标群体具体化为一个研究支持的典型人物。它是 semi-fictional / 半虚构，但依据必须是真实访谈和问卷，不能凭空编一个“爱买本产品的 Max”。问顾客真正看重哪些产品属性，后面画感知图要用。（课件 pp. 21–22）

4. Positioning：你说自己高级没用，顾客觉得才算

Positioning / 定位是产品相对于竞争者，在目标顾客心中占的位置。好的定位要 attractive / 对目标顾客有吸引力、differentiated / 与对手不同、consistent / 与品牌一致。品牌能主动塑造印象，但最终位置由顾客的感知决定。（课件 p. 27）

课件给出三个可强调的基础（p. 28）：attributes & benefits / 属性与利益，例如可维修性；use & occasion / 用途与场景，例如儿童零食与成人聚会；versus competitors / 相对竞争者，突出与对手不同。选哪一个，要看目标群体是否在乎、品牌是否有证据支撑。

感知图 / Perceptual map：把“你在我心里”画出来

挑两个目标顾客真正看重、彼此尽量独立且能拉开品牌差异的维度，例如价格与口味丰富度；让消费者评价主要品牌，再把品牌放到两个轴上。空白处只是值得研究的机会，不是“那里一定有人买”。先查需求、利润和自身能力，再决定是否进入。（课件 pp. 29–32、37）

课件计算题提醒： 属性重要性（如 7/10）× 品牌在该属性的表现评分（如 9/10）＝该属性加权分（63）；几个属性的分数可相加形成比较指数。总分是一维综合指数，二维感知图则保留两个维度的位置，不要把总分当成地图的 X/Y 坐标。权重应来自目标顾客研究。（课件 pp. 31–32）

一句话写出定位 / Positioning statement

公式 / Formula（课件 p. 34）： For [target] who [need/opportunity], [brand/product] is the [category] that [key benefit] because [reason to believe].

中文： 对于谁，他们有什么需要，我们的什么产品属于什么品类，能带来哪项关键利益，因为我们有什么可信证据。

原创示范： “For students who need a laptop that lasts through university, ReLoop is the repairable laptop that reduces replacement hassle because its battery and storage can be replaced locally.” / “对于希望电脑陪自己读完大学的学生，ReLoop 是一款可维修笔记本，减少换机麻烦，因为电池和存储可在本地更换。”这里的最后一句是理由；真实品牌在使用前仍要核实是否确有该服务。

自检三问： 目标顾客真的在乎吗？与竞争者明显不同吗？与品牌已有形象一致吗？写得漂亮却拿不出证据的承诺，只是口号。（课件 pp. 33–36）

5. 临考 45 秒：把 STP 接成一条线

  1. Segment： 四类标准 = 人口、地理、心理、行为；好群体过 MASDA 五关。
  2. Target： 吸引力看规模/增长和竞争，最后还要看公司是否有本事服务；策略从大众、差异化、利基到个人定制。
  3. Position： 在目标顾客心智里相对对手占位；用目标顾客关心的轴画图，再用“对象＋需要＋品类＋利益＋证据”写定位陈述。

串联前四单元： Session 3 告诉你顾客怎么想，Session 4 教你拿真实证据，Session 5 才有资格决定服务谁、承诺什么；定位随后应指导 4Ps，而不是写在 PPT 里就结束。（课件 pp. 39、41）

Part B · SWOT 分类案例 / SWOT classification case

English case: Camille plans to open a French pastry bakery in a mid-size city. Classify each item as S, W, O, or T. Assume the wording refers to Camille's proposed business and its local market.

中文案例： Camille 计划在一座中等城市开一家法式糕点店。根据她拟开的店与当地市场，把每项归为 S 优势、W 劣势、O 机会、T 威胁。

  1. Camille holds a respected French pastry qualification. / Camille 拥有受认可的法国糕点师资格。
    答案：S 优势。 这是她已拥有的内部能力。/ An existing internal capability.
  2. She has never managed digital advertising. / 她从未管理过数字广告。
    答案：W 劣势。 自身技能缺口。/ An internal skill gap.
  3. Local demand for artisan pastries is rising. / 当地对手工糕点的需求正在上升。
    答案：O 机会。 外部市场的有利变化。/ A favorable external trend.
  4. Two established bakeries are expanding nearby. / 附近两家老牌面包店正在扩张。
    答案：T 威胁。 竞争环境中的不利变化。/ An unfavorable competitive development.
  5. She already has an agreement with a reliable French flour importer. / 她已与可靠的法国面粉进口商达成协议。
    答案：S 优势。 已获得的供货关系是自己的资源。/ An existing resource of her business.
  6. Local rents for small retail premises are rising. / 当地小型商铺的租金正在上涨。
    答案：T 威胁。 外部成本环境变差。/ A worsening external cost condition.
  7. Her team can produce distinctive gluten-free pastries. / 她的团队能做出有特色的无麸质糕点。
    答案：S 优势。 团队现有的产品能力。/ A current internal capability.
  8. A local café invites her to discuss a wholesale partnership. / 一家当地咖啡馆邀请她讨论批发合作。
    答案：O 机会。 还在讨论中的外部合作机会；若日后签成稳定独家协议，可成为内部资源。/ A potential external opportunity, not yet an owned asset.
  9. The city announces stricter food-packaging requirements next year. / 市政府宣布明年将实施更严格的食品包装规定。
    答案：T 威胁。 外部法规可能增加合规成本。/ External regulation may raise compliance costs.
  10. She has little cash available for the launch. / 她可用于开店的现金不多。
    答案：W 劣势。 自己的资金限制。/ An internal funding constraint.

SO 战略示例 / Example SO strategy: 用 Camille 的专业资质和特色产品（S）满足当地上升的手工糕点需求（O）。/ Use her pastry skills and differentiated offer to serve growing artisan demand.

Part C · Consumer and research case / 消费者与研究案例

English case: A repairable-laptop brand wants to launch in France. It considers students who want devices that last longer and generate less waste. The team first reads published repairability reports, then interviews six students. It later surveys 28 students recruited from one campus. A prototype page gets many visits but few purchases. Interviews reveal that buyers like the repairable design but cannot tell whether the laptop can run course software.

中文案例： 某可维修笔记本电脑品牌准备进入法国。它考虑把希望设备用得更久、减少废弃物的学生作为目标顾客。团队先阅读已发表的维修性报告，再访谈 6 位学生，随后调查从同一校园招募的 28 位学生。原型产品页访问量不少，却很少成交。访谈发现顾客喜欢可维修设计，但不确定电脑能否运行课程软件。

C1. “Students who value long product life and less waste” describes primarily a target's:
A. lifestyle and values B. age alone C. supplier power D. sales promotion
中文： “看重产品寿命与减少废弃物的学生”主要描述目标顾客的什么？A. 生活方式与价值观；B. 只有年龄；C. 供应商议价能力；D. 促销。
答案 / Answer: A. 这是态度和价值观，不只是人口年龄。/ These are values and lifestyle, not age alone.

C2. The published reports and six new interviews are respectively:
A. primary/secondary B. secondary/primary C. both primary D. both secondary
中文： 已发表报告和新做的 6 次访谈分别属于？A. 一手/二手；B. 二手/一手；C. 都是一手；D. 都是二手。
答案 / Answer: B. 已有报告是二手；为当前决策新访谈是一手。/ Existing reports are secondary; new interviews are primary.

C3. The interviews are primarily:
A. qualitative exploratory B. quantitative causal C. a census D. a pricing experiment
中文： 这些访谈主要属于？A. 探索性定性研究；B. 因果性定量研究；C. 普查；D. 价格实验。
答案 / Answer: A. 访谈探索语言、顾虑和动机。/ Interviews explore meanings and concerns.

C4. Which insight best connects evidence to a decision?
A. “The page had many visits.” B. “Students want clear proof of software compatibility before buying; show supported software on the page.” C. “Six people were interviewed.” D. “The product is definitely suitable for all French students.”
中文： 哪句洞察最能把证据与决策连接起来？A. “页面访问量不少”；B. “学生购买前需要软件兼容性的明确证据；应在页面列出支持的软件”；C. “访谈了 6 人”；D. “产品肯定适合所有法国学生”。
答案 / Answer: B. 它解释购买障碍，并指出可执行的改动。/ It explains the barrier and suggests a decision.

C5. What is the most important limit of the 28-person survey?
A. It has no primary data. B. It cannot automatically represent all French students. C. It is always invalid because it uses numbers. D. It proves repairability caused purchase intention.
中文： 这份 28 人问卷最重要的限制是什么？A. 没有一手数据；B. 不能自动代表所有法国学生；C. 只要使用数字就无效；D. 证明了维修性导致购买意向。
答案 / Answer: B. 同一校园的便利样本不能直接外推到总体。/ A one-campus convenience sample does not establish national representativeness.
